## 3. The 10 fatal marker gaps (2 files)
Audit-1.txt lines 1844-1855, reason fatal-no-safe-anchor: /products/orca/ → src/pages/products/orca.njk; /products/search/ → src/pages/products/search.njk. Fields: faq, schema, internal-links, expand-content, qa-content. Shared layout product-v2.njk (also /products/ai-crm/), data in src/_data/platformProducts.js.

### 3a. Why detectors fail (verified by running detectInsertionPoint)
Both are 11 lines of front matter + empty body → no-confident-html-container; fragment detector no-fragment-body (< MIN_CONTAINER_TEXT 40); before-footer no-footer. Threshold refusal, not real ambiguity. Control: ai-crm.njk has a JSON-LD script >40 chars so it resolves.

### 3b. Proposed manual insertion (EOF after closing `---`)
```
<!-- SEOAI:FAQ:START --><!-- SEOAI:FAQ:END -->
<!-- SEOAI:SCHEMA:START --><!-- SEOAI:SCHEMA:END -->
<!-- SEOAI:INTERNALLINKS:START --><!-- SEOAI:INTERNALLINKS:END -->
<!-- SEOAI:EXPANDEDCONTENT:START --><!-- SEOAI:EXPANDEDCONTENT:END -->
<!-- SEOAI:QACONTENT:START --><!-- SEOAI:QACONTENT:END -->
```
### 3c. NOT inert
Comments inert (.eleventy.js has no minify/comment-strip), BUT product-v2.njk line 1914 `{% if content and content.trim() %}<section class="px-4 py-12 sm:px-6 sm:py-16 lg:px-8 lg:py-20">…` renders an empty padded section for a marker-only body (evidence: live ai-crm has 14 `action-center-content` matches; orca/search 0). Visible layout change = design-preservation violation. Options: (1) layout guard `{% set acContent = content | replace(r/<!--[\s\S]*?-->/g, '') %}{% if acContent and acContent.trim() %}` in product-v2.njk (needs Nunjucks version check); (2) skip markers, use FAQ adapter (3d), leave other four fields blocked.

### 3d. Recommended for FAQ
```json
{ "match": "^/products/(orca|search|ai-crm)/?$",
  "adapters": { "faq": { "id": "data-array-content", "format": "js-export-array", "idField": "id",
                          "dataFile": "src/_data/platformProducts.js", "itemsField": "faq" } } }
```
Layout renders product.faq as accordion; base.njk (~253-260) emits FAQPage JSON-LD from same items → no duplicate. Orca data header says "no fabricated stats, clients, or FAQ": owner must confirm an Orca FAQ is wanted. Dry-run on a copy first.

### 3e. Safety
Marker-only PR without the layout guard is NOT automated-safe. With guard: manual review of 2 small diffs, low risk.
